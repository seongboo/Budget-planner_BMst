# 식비 가계부 (Budget Planner)

하루 허용 식비를 정하고, 아낀 돈을 **세이브 잔액**으로 쌓아 가는 가계부입니다.
서버 없이 브라우저에서만 동작하며, 입력한 데이터는 **내 기기(브라우저)에만** 저장됩니다.

**사용하기:** https://seongboo.github.io/Budget-planner_BMst/

## 설치 (폰 홈 화면)
1. 폰의 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 ⋮ 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.

## 사용법
1. **설정** 탭에서 고정 수입, 고정지출, 월 식비 예산을 입력합니다.
2. **홈** 탭에서 지출을 입력합니다. 집밥을 먹은 날은 입력하지 않으면 됩니다.
3. 홈 탭에서 오늘 남은 허용 식비, 누적 세이브 잔액, 이번 달 남는 돈을 확인합니다.

## 계산 방식
월 식비 예산을 M, 그 달의 일수를 N이라 하면 하루 허용액은 a = M / N 입니다.

- **세이브 잔액**: 매일 B ← B + (a − 그날 식비). 집밥이면 a가 그대로 쌓이고, 월이 바뀌어도 이월됩니다.
- **큰 지출**: 입력할 때 두 방식 중 선택합니다.
  - 잔액 차감: B에서 바로 뺍니다. B가 음수가 되면 남은 날의 하루 허용액을 줄이도록 안내합니다.
  - 균등 분할: 남은 날에 나누어 하루 허용액에서 뺍니다.
- **고정지출 결제**: 하루 허용액과 B에 영향을 주지 않습니다. (예산 − 실제 결제액)의 차이가 이번 달 남는 돈에 반영됩니다. 같은 달 같은 항목은 마지막 입력만 반영합니다.
- **교통·쇼핑·문화·취미**: 이번 달 남는 돈에서 차감됩니다. 하루 허용액과 B에는 영향이 없습니다.
- **이번 달 남는 돈** = 수입 − 고정지출 − 식비 예산 + 고정지출 절약분 − 기타 지출

## 데이터와 백업
- 데이터는 브라우저의 localStorage에만 저장되며 서버로 전송되지 않습니다.
- 브라우저 데이터를 지우거나 기기를 바꾸면 기록이 사라집니다. 설정 탭의 **JSON 내보내기**로 가끔 백업하세요.
- 기기 간 동기화는 지원하지 않습니다.
